# Independent Windows installation checklist

A new virtual environment on the developer's existing machine is a useful test, but not an independent clean-OS test. This checklist is ready for another tester; it has not been signed off automatically.

- [ ] Record Windows version, existing Python version, CPU/GPU and available storage without machine/user identifiers.
- [ ] Download the published setup ZIP, verify SHA256, extract into a writable folder and open the setup helper.
- [ ] Complete controls-only setup; record wall time, downloaded size and final folder size.
- [ ] Open the generated controls demo, use picture/audio controls, export and restart.
- [ ] Install base models separately; analyze a permitted short local file and inspect its timeline.
- [ ] Save a local mistake report and review it; verify no automatic uploads or training.
- [ ] Test retry after an interrupted download and helpful failure when Python/storage is missing.
- [ ] Submit a sanitized installation report, stating whether this was a fresh OS or an existing machine.

Do not claim recognition quality from a successful installation. Do not attach private media, raw transcripts, tokens or a whole runtime directory.
