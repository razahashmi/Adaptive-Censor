# Roadmap

This is an ordered plan, not a delivery-date promise.

**Now — usable preview:** predictable Windows CPU setup, clear local-only behavior, reproducible public diagnostics, accessible controls, recovery tests and clear distinction between suggestions and accepted filters.

**Next — better evidence:** human-reviewed public examples, more independent titles and categories, regional pixel supervision, multilingual speech evaluation, measured hardware configurations and rejection of uncertain visual predictions.

**Later — supported home clients:** authenticated access, household profile permissions, secure streams, bounded queues, result caching/versioning, device compatibility and multi-viewer capacity tests. Universal protected-stream filtering is not promised.

Track proposed work in [Issues](https://github.com/razahashmi/Adaptive-Censor/issues); use [starter task drafts](STARTER_TASKS.md) for concrete first contributions.
