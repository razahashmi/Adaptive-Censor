# Starter tasks for contributors

These are ready-to-file issue drafts; no issue has been posted automatically.

| Task | Scope | Acceptance |
|---|---|---|
| First-run screen-reader audit | Player/setup guidance | Keyboard path through import, rules, review and reporting; documented screen-reader results and focused fixes |
| Independent Windows setup report | CPU setup ZIP | Clean Windows/Python version, download/storage/time, successful controls demo and restart; no private media |
| Human-review the public starter | `samples/public-suite.json` | Exact word/kiss boundaries, explicit unknowns, reviewer and source identities; no fabricated labels for absent categories |
| Add a licensed hard negative | Public starter | Clear redistribution terms, source checksum, title identity and reviewed category/timing; no private TV/movie excerpts |
| Improve timeout recovery | Local inference/export | Reproducible failure, helpful UI status, retry without duplicate sessions/reports, meaningful regression test |
| Measure a second hardware configuration | Benchmark command | Exact config/models, complete pipeline wall time, memory and disclosed draft/independent status |

Use the corresponding issue form, describe expected behavior and attach only sanitized, permitted evidence. A maintainer can label a posted task `good first issue` after checking scope.
