01 / FIND

What should we look for?

Processing settings

The scene model first scans surrounding context, then checks each candidate using five distinct nearby frames, about 80 ms apart. A candidate alone cannot trigger filtering. It uses the GPU independently of the speech and anatomy setting. Scene decisions require confirmation by default. Automatic mode is experimental; uncertain decisions and CLIP suggestions always require confirmation. The larger speech model uses more compute and needs its model installed once. Changing models requires reanalysis. Higher sampling can catch shorter shots, but even 8 samples per second can miss brief images. The player waits if analysis falls behind. Existing learned detectors are available for review. Automatic learned filtering requires a complete player-pipeline evaluation with independent human labels and sufficient events across titles. Candidate checks are explicit and off by default; each setting needs its own evaluation. Learned models need an NVIDIA GPU. Optional anatomy region checks can reduce false blurs but may reject real anatomy; they remain experimental and require reanalysis after changes.

Detection runs locally after model setup.

Know what the models can miss

Speech recognition can mishear words. Anatomy detection does not establish sexual context. Sequence verification checks sampled images together but can still invent or miss content. CLIP is available only as a source of review suggestions.

This preview has not been validated as a reliable child-safety filter. Review important media before relying on its decisions.
