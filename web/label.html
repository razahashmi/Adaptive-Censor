    DEFINITIONS · REVISION

    HOW TO LABEL

    • Watch the whole window (between the shaded context). Use 0.5× or frame steps for brief moments.
    • Choose a category. Use Mark start and Mark end for every matching span. Brief flashes count.
    • Labels save automatically as you edit. Done reviews all five categories and opens the next unfinished window after saving.
    • No content in a category? Leave it empty. Done records it as reviewed with none present.
    • Use Ambiguous for spans you genuinely cannot decide; they are excluded from scoring.
    • Mark a category Unsure only if the whole window cannot be judged for it.
    • On validation and test windows, label before looking at model drafts.
